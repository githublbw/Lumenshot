# Lumenshot 用户级安装

当前可用版本面向 Ubuntu 22.04 的 GNOME X11。系统桌面截图、托盘和快捷键需要在登录桌面后使用。打开「显示应用程序」搜索 Lumenshot，所有截图和编辑功能都可以用鼠标操作。

## 安装与升级

当前开发机已配有专用 Qt 运行库。其他 Ubuntu 22.04 机器可用系统的开发包构建，依赖包括 g++、CMake、make、qt6-base-dev、qt6-qpa-plugins 和 libxcb1-dev。安装这些系统包需要系统权限，以下应用安装操作只涉及当前用户。在项目根目录运行：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build --parallel
ctest --test-dir build --output-on-failure
bash packaging/user-install.sh install build/lumenshot
```

升级时在菜单中选择「退出 Lumenshot」，使用新版源码重复上述命令，然后从应用菜单打开。登录启动项、保存目录设置和现有图片沿用原位置。

## .deb 安装包（推荐）

把项目打成自包含 .deb：安装到 `/opt/lumenshot`（自带私有 Qt 运行库与 OCR 模型），并注册命令行、应用菜单和图标，`sudo apt install ./lumenshot_xxx_amd64.deb` 一条命令完成安装/升级/卸载。

打包前先完成一次源码构建，并确保当前机器已执行过一次用户级安装（提供私有 Qt 运行库来源），然后在项目根目录运行：

```bash
VERSION=2026.11.21 bash packaging/build-deb.sh ~/.cache/lumenshot-build/build/lumenshot
sudo apt install ./packaging/lumenshot_2026.11.21_amd64.deb
```

- 安装后命令 `lumenshot`、应用菜单、开机自启（如已开启）都指向 `/opt/lumenshot`。
- 从旧的用户级安装迁移：安装 .deb 时会自动移除旧菜单入口并把登录自启切到新安装；旧程序文件可用 `bash packaging/user-install.sh uninstall` 清理。
- 升级：重新构建后再次 `sudo apt install ./...deb`；卸载：`sudo apt remove lumenshot`（截图文件与偏好设置保留）。
- 依赖为 Ubuntu 22.04 桌面自带库（libicu70 等），其他发行版未验证。

## 文字识别（OCR）

浮动工具栏的「提取文字」按钮（快捷键 `O`）可识别当前截图中的文字，识别全程在本机完成，截图不会上传网络。结果窗内可手动修正后一键复制。识别引擎为 RapidOCR（PP-OCRv4，中英双语），模型与推理库随应用一起安装在 `~/.local/opt/lumenshot` 下。竖排文字、艺术字和严重噪点场景识别率会下降。onnxruntime 运行库与头文件已随仓库 `third_party/onnxruntime` 提供，OCR 模型在 `assets/ocr`；该组件缺失时应用仍可正常构建，只是不显示识别按钮。

## 常用操作

- 关闭工作台会留在后台；点托盘或应用菜单可重新打开。退出进程请用「菜单 → 退出 Lumenshot」。
- 「菜单 → 设置」可开启登录自启、更改保存目录或换键。默认快捷键为 Ctrl+Alt+A，遇到冲突可以换一组按键或直接点击截图。
- PNG 保存失败时检查目录写入权限和可用空间。需要遮住敏感内容时使用不透明矩形或椭圆。
- 当前正式应用仅在 X11 实现截图。Wayland 的系统截图许可、快捷键与置顶仍在验证中。

## 卸载

先退出后台进程，再从项目根目录运行：

```bash
bash packaging/user-install.sh uninstall
```

脚本移除当前用户的程序、命令、菜单入口和 Lumenshot 自启项。手动保存的图片及偏好设置会保留。
