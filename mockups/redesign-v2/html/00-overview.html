10 种造形语言

10 Constructions

同一个界面、同一套色板、同一组 16 枚功能，只改变几何构造。每套都经过黑白剪影测试，去掉颜色后仍能彼此区分。

16每套图标
24统一网格 / px
10造形语法
01

角标

Corner Marks

只用四角与刻度定义边界，像印刷套准标记。

CORNER / TICK / SQUARE NODE / OPEN FORM
01每个图标最多四个角标，绝不画完整外框
02角标长度固定 4.8，方向一律朝内
03中心信息只用 2px 实心方点或圆点表示
Silhouette / 剪影
角标刻度套准不闭合
描边 1.70 pxMIN 14 px
02

实心

Solid

用正负形代替线条，先有重量，再读细节。

SOLID MASS / NEGATIVE SPACE / ROUNDED CUT
01外形全部实心，细节只靠挖空表达
02圆角统一 2px，外轮廓不留尖角
03最小负形间隙 1.5px，保证 15px 可读
Silhouette / 剪影
正负形实心剪影挖空
填充 SolidMIN 14 px
03

节点

Node Graph

把图标画成电路：线是连接，点是决策。

POLYLINE / DOT AT EVERY JOINT / 90° + 45° / ORBIT
01所有转折点都放一颗 2.7px 节点，不允许裸转角
02直线只允许 90° 与 45°，圆是唯一的闭合轨道
03线宽 1.1px，节点直径至少是线宽的两倍
Silhouette / 剪影
节点连线直角电路感
线宽 1.10 pxMIN 16 px
04

断口

Notch

每个图标都被切了一刀，缺口本身就是方向。

OPEN CONTOUR / 45° CUT / DETACHED SHARD
01每枚图标至少留一个 45° 缺口，绝不闭合
02缺口宽度固定 3px，不做圆滑过渡
03断开的碎片保留，作为造型的第二笔
Silhouette / 剪影
断口碎片切开开放轮廓
描边 1.90 pxMIN 15 px
05

等轴测

Isometric

把工具放倒，让它们在 30° 网格上站起来。

30° ISO PROJECTION / FACE + DEPTH / NO FLAT VIEW
01统一 30° 等轴测投影，不混用平面视图
02每个形体保留 2px 厚度，方向一致
03不画隐藏边，靠面与面的明暗区分
Silhouette / 剪影
等轴测厚度菱形立体
线宽 1.50 pxMIN 18 px
06

一笔

One Line

不提笔，一笔画完；收笔处留一个点。

ONE CONTINUOUS PATH / SELF-CROSS / END DOT
01每枚图标只有一条连续路径，不拆分部件
02允许回笔与自交，用重叠线制造转折
03收笔统一落一个 3.4px 圆点作为签名
Silhouette / 剪影
一笔连续回笔圆点
描边 2.00 pxMIN 16 px
07

拼贴

Collage

圆、方、三角各自独立，靠位置发生关系。

DISCONNECTED PRIMITIVES / GAP / 3-STEP INK
01只用圆、半圆、矩形、三角四种原语
02部件之间至少留 1.5px 空隙，不粘连
03用 35 / 65 / 100% 三层墨色建立前后关系
Silhouette / 剪影
拼贴包豪斯错位几何
原语 4 种MIN 15 px
08

像素

Pixel

把 24px 拆成 12×12 个方格，只允许整格落子。

12 × 12 GRID / 2PX CELL / CRISP EDGE
01所有边缘必须落在 2px 网格线上，不允许半格
02不使用曲线与圆角，转角一律硬切
03单个连通块最小 1 格，避免缩小后消失
Silhouette / 剪影
像素网格硬边8-bit
格宽 2.0 pxMIN 14 px
09

双线

Inline

每根线都画两遍，中间留 1.6px 的呼吸。

DOUBLE CONTOUR / 1.6PX GAP / PARALLEL PAIR
01每枚图标至少有一组内外双轮廓
02双线间距固定 1.6px，沿所有方向等距
03内外线同宽 1.3px，不分主次
Silhouette / 剪影
双线刻字内轮廓平行
描边 1.30 pxMIN 16 px
10

圆规

Compass

只允许圆、弧和点，直线在这里不存在。

CIRCLES / ARCS / DOTS ONLY / NO LINE
01禁止任何直线段与尖角，只使用圆、弧、椭圆、点
02所有开放弧至少留 45° 缺口，避免误读为整圆
03端点统一用实心圆点收束，半径 1.6–2.2px
Silhouette / 剪影
圆规轨道弧线星盘
描边 1.70 pxMIN 16 px
