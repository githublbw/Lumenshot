## 复现 X11 检查

在项目根目录运行。探针使用系统 Python 3、GTK 3 和 PyGObject，快捷键及自动测试另需 Ubuntu 的 `python3-xlib` 包。本次从 Ubuntu 软件源取出该包，在临时目录核对包校验值并加载，未修改系统安装。正式应用仍按原计划采用 C++ 和 Qt。

```bash
/usr/bin/python3 probes/session_probe.py
/usr/bin/python3 probes/check_x11.py
```

第二条命令会生成一次全局按键和三个短暂窗口。通过时最后一行显示“两个普通窗口获得焦点后，预览均保持在其上方”。手动按键可用 `/usr/bin/python3 probes/session_probe.py --listen --pin` 单独检查。

## 接续 Wayland 验收

1. 保存桌面工作，注销，在登录界面选择启用 Wayland 的 Ubuntu 会话。进入桌面后用 `echo "$XDG_SESSION_TYPE"` 确认输出 `wayland`。
2. 在 GNOME 设置的「键盘 → 自定义快捷键」中创建一个临时测试绑定，选用未占用的组合键。命令为 `/usr/bin/python3 /home/autin/Desktop/project/Lumenshot/probes/session_probe.py --pin`。这条命令也可直接在终端运行以查看结果。
3. 按绑定键调出系统选择器，记录可选模式。分别测试整屏、区域、窗口（若提供），核对预览内容与所选范围；终端启动时记录返回尺寸。记录是否每次都需授权，以及系统是否在图片目录留下文件。探针只读取返回的本机文件。
4. 在系统选择器取消，确认没有预览；再次运行并完成截图。若系统提供拒绝授权选项，单独测试并记录桌面提示。
5. 打开一次预览，切换到两个其他窗口，观察图片是否仍可见。如果不能，在预览标题栏菜单尝试「总在最前」并重测。记录自动置顶、系统手动置顶或不可用。用完移除临时按键绑定。
